# Zignatures

Native r2 function signatures for identifying library functions in stripped binaries.
Loaded with `zo <file>`; matching is done with `z/`.

## Quick Start

```r2
# Load a zignature file
zo ~/.local/share/radare2/zigns/musl/aarch64/musl-libc.zsig

# Search for matches in current binary
z/

# List matched functions
afl~zign.
```

## Tier Layout

Tier definitions are in `tiers.json`. The `core` tier (~46 MB) is required;
`vendor`, `debian-large`, and `windows-large` are optional.

| Tier | Directories | Size |
|------|------------|------|
| `core` | musl, uclibc, openwrt, embedded, glibc | ~46 MB |
| `vendor` | android, cisco-ios, dji, go, juniper, macos, vxworks | ~96 MB |
| `debian-large` | debian | ~347 MB |
| `windows-large` | windows | ~349 MB |

### `windows/` — Windows VC++ Runtime

VS2008 through VS2022, x86 / x64 / arm64. Covers:
- `vcruntime140` — core CRT (memcpy, malloc, exception handling)
- `ucrtbase` — Universal CRT (printf, fopen, etc.)
- `msvcp140` — C++ STL (std::string, std::vector, streams)
- `concrt140`, `vcamp140`, `vcomp140` — Parallel Patterns / OpenMP
- `mfc140`, `atl` — MFC and ATL frameworks

**Note:** `windows/` is exempt from the orphan-zsig check — the ~180 MFC/ATL/vcamp
extras are available for manual `zo windows/x64/vs2022-mfc140.zsig` use and are not
auto-loaded by the standard Windows profiles.

### `sessions/` — Per-Binary Session Corpus

Zsig files generated from specific analyzed binaries during AETHER sessions.
Named by source binary hash. The `index.json` manifest maps hashes to metadata.

```json
{
  "0d97def03812819a": {
    "entry_count": 312,
    "named_pct": 100,
    "note": "Generated by corpus_commit.py | merged absorb key 403d19d7c890fd17",
    "sample_names": ["isspace", "strstr", "gettimeofday", "malloc"],
    "source_binary": "76bb8697f3c8bec8"
  }
}
```

**Current sessions (8 total):**

| Hash | Entries | named_pct | Source binary |
|------|--------:|:---------:|---------------|
| `0d97def03812819a` | 312 | 100% | `76bb8697f3c8bec8` |
| `18498ce90aedcd34` | 716 | 100% | `5f4a8be1aaf9ead7` |
| `6351a647dd2ea8f6` | 3,180 | 100% | `6351a647dd2ea8f6` |
| `8073dc82fc3f4caa` | 4,410 | 100% | `193a2ccb7fa04c77` (Supermicro BMC `Auth`) |
| `daed52b867799857` | 1,354 | 100% | `5716572fb55ea25f` |
| `de2cc34b9686e5da` | 510 | 0% | self-referential (archived — all `fcn.*`, zero cross-binary value) |
| `f29d5e39bd05d704` | 313 | 100% | `IPMI_OEM_f29d5e3` |
| `fc531267fc2f85a8` | 66 | 100% | `fc531267fc2f85a8` |

Query the index to find sessions for a target binary:
```bash
python3 -c "
import json
d = json.load(open('~/.local/share/radare2/zigns/sessions/index.json'))
for h, m in d.items():
    print(h[:16], m.get('source_binary','?'), m.get('entry_count',0), m.get('named_pct','?'))
"
```

Load manually:
```r2
zo ~/.local/share/radare2/zigns/sessions/8073dc82fc3f4caa.zsig
z/
```

## Generating New Zignatures

```bash
# Debian/Ubuntu libraries (amd64, arm64, armhf, i386)
python3 tool/generate-debian-libs-zsig.py --arch armhf

# macOS libSystem + libm (no Apple hardware needed)
python3 tool/generate-macos-zsig.py

# musl libc (all architectures)
python3 tool/generate-musl-zsig.py --all

# Android NDK
python3 tool/generate-ndk-zsig.py --all

# FreeRTOS Cortex-M
python3 tool/generate-freertos-zsig.py

# uClibc ARM32 / ARM64
python3 tool/generate-uclibc-arm32-zsig.py
python3 tool/generate-uclibc-arm64-zsig.py

# Go standard library
python3 tool/generate-go-zsig.py

# Windows VC++ runtime
python3 tool/download-vcredist.py --all
python3 tool/generate-vcruntime-zsig.py --version 2022 --arch x64

# OpenWrt musl (per target)
python3 tool/generate-openwrt-musl-zsig.py --target mips_24kc

# VxWorks libraries
python3 tool/generate-vxworks-zsig.py --arch x86_64

# Juniper kmd
python3 tool/generate-juniper-zsig.py
```
